# Privacy Policy — Kartaan Seller Assist

Last updated: 29 August 2026

**This extension collects no data whatsoever.**

- It does not collect, store, or transmit personal information.
- It does not contact any server. There is no backend, no analytics, no telemetry.
- It has no accounts and no login.
- It does not read your browsing history or activity on any other site.

## What it actually does

The extension runs only on `https://*.synlabs.io/*`. On the VMS operator screen it
watches the Record/Stop button's visible text. When a recording stops, it clears the
AWB text box on that page and places the cursor in it.

The AWB number is read only to check whether the box is empty. It is never stored,
copied, or sent anywhere. It exists only in the page you are already looking at.

## Permissions

The extension requests no special browser permissions. It only declares the single
site above, which is required for a content script to run there at all.
